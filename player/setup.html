1. Spotify-App anlegen (einmalig)

  1. developer.spotify.com/dashboard öffnen, mit deinem Spotify-Konto anmelden, Create app.
  2. Name z. B. SpotifyHomeserver, Beschreibung beliebig.
  3. Redirect URI genau so eintragen: http://127.0.0.1:8080/callback
  4. Bei „Which API/SDKs“ Web API ankreuzen, speichern.
  5. In den App-Einstellungen die Client ID kopieren (das Client Secret wird nicht gebraucht).

3. Einmal anmelden

Die Anmeldung muss im Spotify-Fenster auf dem Server passieren (wegen der Adresse 127.0.0.1): Auf der Hauptseite das Bild einschalten, im VNC-Fenster den Browser Falkon öffnen (Rechtsklick auf den Desktop → Terminal: falkon http://127.0.0.1:8080/login) – oder einfacher: unten auf den Knopf klicken, dann öffnet der Server Falkon selbst im VNC-Bild.
